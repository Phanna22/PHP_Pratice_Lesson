PHP FORM LAB

10 hands-on projects

Choose a project to practise PHP forms with a modern responsive interface.

Project library

  1. Personal Information Form · Collect and display a person's details.
  2. Student Registration · Register a student with contact and course details.
  3. Smart Calculator · Calculate two numbers using a selected operator.
  4. Login Form · Practice checking a username and password safely.
  5. User Registration · Validate a new account's details and password confirmation.
  6. Exam Result Calculator · Calculate total, average, grade and pass/fail.
  7. Contact Us · Validate a contact message. This demo does not send email.
  8. Product Order Form · Calculate order subtotal and shipping.
  9. Form Validation Lab · Practice server-side validation rules.
  10. Student Management · Add a student record and list records during this session.

Run locally

Copy this folder into C:\xampp\htdocs\, start Apache in XAMPP, then open:

http://localhost/php-form-projects/

Most projects process data only for the current request. Project 10 uses a PHP session. Add MySQL for permanent storage.
